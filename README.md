# JavaScript/TypeScript VS Code Profile

A comprehensive VS Code profile optimized for modern JavaScript and TypeScript development, featuring essential extensions, custom settings, and productivity enhancements.

## 🚀 Overview

This profile is designed for developers working with:
- **JavaScript & TypeScript** projects
- **React, Next.js, Svelte** frameworks  
- **Node.js** backend development
- **Tailwind CSS** styling
- **Prisma** database management
- **Git** version control with GitHub integration

## ✨ Key Features

### 🎨 **Visual & UI Enhancements**
- **GitHub Dark** theme for comfortable coding
- **Catppuccin Icons** for better file recognition
- **JetBrains Mono** font with ligatures enabled
- Optimized line height (1.65) and cursor animations
- Clean interface with minimap disabled and sticky scroll off

### ⚙️ **Editor Configuration**
- **2-space indentation** for consistent formatting
- **Word wrap** at 300 characters with smart indentation
- **Auto-save disabled** for manual control
- **Linked editing** for HTML/JSX tags
- **Bracket pair guides** and smooth cursor animations

### 🛠️ **Development Tools**
- **ESLint** integration with auto-fix on save
- **Prettier** formatting (disabled in favor of ESLint)
- **Auto import management** for TypeScript
- **Tailwind CSS IntelliSense** with custom class detection
- **GitHub Copilot** for AI-powered code completion

### 📁 **File Management**
- Extensive file/folder exclusions for cleaner workspace:
  - `node_modules`, `.next`, `dist`, `build`
  - `.git`, `.vscode`, `.turbo`, `.vercel`
  - Test results, lock files, and generated content
- Smart search and watcher exclusions for better performance

## 📦 Installation

1. **Export this profile** from VS Code:
   - Open Command Palette (`Ctrl+Shift+P`)
   - Run "Profiles: Export Profile"
   - Save the `.code-profile` file

2. **Import on another device**:
   - Open Command Palette (`Ctrl+Shift+P`)
   - Run "Profiles: Import Profile"
   - Select the exported `.code-profile` file

3. **Alternative: Manual Setup**
   - Install the listed extensions manually
   - Copy settings from the profile configuration
   - Set up custom keybindings
